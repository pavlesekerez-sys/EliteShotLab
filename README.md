# EliteShotLab 🏀

EliteShotLab is an Android basketball development app built with Kotlin and Jetpack Compose.

## Current build
- Dark graphite interface with orange accents
- Home dashboard and six main navigation areas
- 16-week development roadmap:
  1. Foundation (Weeks 1–4)
  2. Separation (Weeks 5–8)
  3. Game Speed (Weeks 9–12)
  4. Performance (Weeks 13–16)
- GitHub Actions workflow builds a debug APK automatically.

## Build an APK
Open the **Actions** tab in this repository, select **Build EliteShotLab APK**, and run the workflow with **Run workflow**. When it completes, download the `EliteShotLab-debug-apk` artifact.

## Tech
- Kotlin
- Jetpack Compose
- Material 3
- GitHub Actions (remote Android build)

This is an early starter build. Training logs, calendar scheduling, progress analytics, persistence, and AI coaching will be added in later iterations.
